MIMUS

La cartella del server sul tuo Mac, anche quando sei fuori ufficio. Guida per la versione 1.6.1.

Il nome viene dal Gallimimus, il dinosauro corridore.

Installazione

  1. Apri il file MIMUS-1.6.1.dmg (doppio clic). Si apre una finestra come questa.
  2. Trascina l’icona sulla cartella Applicazioni. Poi puoi chiudere la finestra ed espellere il disco «MIMUS» dalla barra laterale del Finder.
  3. Apri MIMUS dalla cartella Applicazioni (non dalla finestra del DMG).
    La prima volta macOS dice che non può verificare l’app, perché non è distribuita dall’App Store. È normale: vai in Impostazioni di Sistema → Privacy e sicurezza, scorri in basso e premi Apri comunque. Serve solo la prima volta.

Primo avvio: configurazione

L’app fa poche domande, una alla volta. Le risposte te le dà l’ufficio IT.

DomandaCosa scrivere
Indirizzo del server remotoindirizzo IP o nome del server, es. 192.168.1.10. Puoi anche incollare l’indirizzo completo come lo usi nel Finder o in Windows (smb://server/Cartella o \\server\Cartella): l’app lo divide da sola
Cartella remotail nome della cartella condivisa sul server, es. Tecnico; per usarne solo una parte: Tecnico/Progetti
Nome della cartella nel Findercome vuoi vederla sul Mac: viene proposto il nome della cartella remota, puoi scrivere quello che preferisci. Nome e posizione si cambiano anche dopo, in Impostazioni
Utente, Dominiole stesse credenziali del PC dell’ufficio: l’utente senza dominio (es. m.rossi), il dominio nella domanda dopo; se non usi un dominio lascia WORKGROUP
Passwordla tua password di rete (resta salvata sul Mac, nascosta)
Spazio da lasciare liberoquanti GB tenere sempre liberi sul disco: 10 va bene

Prima di finire l’app prova il collegamento: se il server non risponde, la cartella non esiste o la password non è accettata te lo dice subito, e con Correggi ripeti le domande con i valori già inseriti.

Uso quotidiano

Non devi fare niente: all’accensione del Mac la cartella (negli esempi Tecnico, ma ha il nome che hai scelto) si collega da sola. La trovi nel Finder dentro la tua cartella Inizio (la casetta con il tuo nome). Puoi trascinarla nella barra laterale del Finder per averla sempre a portata di mano.

  • I file si scaricano quando li apri e poi restano sul Mac: la seconda volta si aprono subito, anche senza rete.
  • Quando salvi, il file viene caricato sul server remoto dopo pochi secondi.
  • Le modifiche dei colleghi compaiono entro 5 minuti (modificabile in Impostazioni). Per vederle subito: app → Aggiorna cartelle.
  • I file che non apri da 30 giorni (modificabile) vengono tolti dal Mac per fare spazio, ma solo se sono al sicuro sul server remoto. Restano visibili e si riscaricano quando li riapri.

L’icona nella barra dei menu

In alto a destra, vicino all’orologio, c’è il Gallimimus di MIMUS. Ha lo stesso colore delle altre icone di sistema e ti dice a colpo d’occhio cosa sta succedendo:

IconaCosa vuol dire
Dorme (Z Z Z): tutto sincronizzato, non c’è niente da fare. Dorme anche quando sei offline: lavori sui file già sul Mac e le modifiche partono da sole al ritorno in rete.
Corre: sta sincronizzando: carica o scarica file, applica le modifiche fatte offline o aggiorna l’elenco delle cartelle. Puoi continuare a lavorare.
Punto esclamativo: c’è un problema da guardare: password non accettata, modifiche rifiutate dal server remoto, disco quasi pieno, collegamento fermo. Clicca l’icona per leggere cosa succede.

Apri MIMUS… porta al menu completo dell’app. Nascondi l’icona la toglie finché non riapri MIMUS (o fino al prossimo accesso); per toglierla sempre: Impostazioni → Icona nella barra dei menu: no.

Non la vedi? Sui Mac con la fotocamera nello schermo le icone in eccesso restano nascoste dietro la tacca: tieni premuto ⌘ e trascina via qualche altra icona per fare spazio (con ⌘ puoi anche spostare quella di MIMUS). Sulle versioni recenti di macOS controlla anche Impostazioni di Sistema → Barra dei menu, che MIMUS sia consentita.

Sul Mac o solo sul server

Nella cartella collegata ogni file ha un pallino che dice dove si trova:

PallinoCosa vuol dire
Solo sul server remoto. Si scarica da solo quando lo apri (serve la rete).
Su questo Mac. Si apre anche offline. Se non lo usi per un po’ (30 giorni, modificabile) viene tolto dal Mac, ma solo se è al sicuro sul server.
Sempre su questo Mac. Non viene mai tolto; se è una cartella, anche i file nuovi messi dai colleghi vengono scaricati da soli.
Da caricare sul server remoto. L’hai modificato qui; parte da solo appena il server è raggiungibile.

Scaricare, tenere, liberare spazio

Tasto destro su file o cartelle (anche più di uno):

VoceCosa fa
Scarica ora su questo Macscarica subito (una cartella con tutto quello che contiene): utile prima di partire senza rete
Mantieni sempre su questo Macscarica e non toglie mai; per le cartelle vale anche per i file aggiunti dopo. Per smettere: Non mantenere più sempre su questo Mac (la copia resta finché non serve spazio)
Togli da questo Mac (resta sul server)libera spazio: toglie la copia dal Mac, il file resta sul server. Non tocca i file con modifiche ancora da caricare né quelli aperti
I pallini e il menu sono un’estensione del Finder: MIMUS la attiva da sola. Se non li vedi: Impostazioni di Sistema → Generali → Elementi login ed estensioni → Estensioni → Finder (o «Aggiunte») → attiva MIMUS. Si possono spegnere da Impostazioni → Pallini e menu nel Finder.

Lavorare offline

Fuori ufficio, senza rete o senza VPN, la cartella continua a funzionare con quello che hai già sul Mac.

Offline puoi…
Vedere tutte le cartelle remotesì
Aprire e modificare i file che avevi già apertosì
Creare file e cartelle, rinominare, cancellaresì, vengono applicati quando torni in rete
Aprire un file mai aperto primano, va scaricato
Vedere le novità dei colleghino, arrivano quando torni in rete
Prima di partire: apri una volta i file che ti serviranno fuori ufficio, così restano sul Mac.
Le modifiche fatte offline esistono solo sul tuo Mac finché non torni in rete: se il Mac si rompe o viene perso prima, si perdono. Appena puoi, collegati alla VPN.

Quando compare un messaggio

A volte l’app ti chiede cosa fare. Se non rispondi entro un’ora sceglie da sola l’opzione che non perde nessun file.

Lo stesso file modificato da te e da un collega

  • Tieni entrambe (consigliato): la tua versione viene salvata accanto all’originale con «conflitto Mac» nel nome. Poi decidi con calma, magari insieme al collega.
  • Sovrascrivi in remoto: vale la tua, quella del collega viene sostituita.
  • Scarta la mia: vale quella del collega, le tue modifiche si perdono.

Hai rinominato o cancellato offline un file che un collega ha cambiato

Se in remoto esiste già un file con il nuovo nome, l’app propone di usare un nome con «conflitto Mac». Se un collega ha messo file in una cartella che hai cancellato offline, la cartella non viene cancellata e ricevi un avviso.

La password non funziona più

Succede quando cambi la password di rete. L’app smette di provare (così l’account non si blocca) e chiede quella nuova. Dopo Salva si ricollega da sola.

Disco del Mac quasi pieno

L’app libera spazio togliendo i file remoti usati meno di recente (solo se sono al sicuro sul server remoto). Se non basta, ti avvisa: libera spazio cancellando file tuoi o svuotando il Cestino.

Impostazioni

Menu → Impostazioni. Scegli una voce, premi Modifica, cambia il valore. Quando hai finito premi Fine: l’app applica tutto insieme e riavvia il collegamento (i file in attesa non si perdono).

Server, cartella condivisa e posizione dei file si possono cambiare solo quando non ci sono modifiche in attesa di essere caricate: altrimenti l’app te lo dice e salva solo le altre impostazioni. Se sposti i file su un altro disco, quelli già scaricati verranno riscaricati quando li riapri.

Aggiornare e disinstallare

Nuova versione

MIMUS controlla da sola se c’è una versione nuova (quando la apri e una volta al giorno). Se c’è ti mostra le novità: premi Aggiorna e fa tutto lei: scarica, verifica che il file sia integro, sostituisce l’app e riavvia il collegamento. Configurazione, file sul Mac e modifiche in attesa restano.

Puoi controllare anche a mano (menu → Controlla aggiornamenti) o disattivare il controllo automatico in Impostazioni. In alternativa scarica il DMG dalla pagina del progetto su GitHub, trascina l’app in Applicazioni scegliendo Sostituisci e aprila una volta.

Disinstallare

App → Disinstalla. Alla fine trascina l’app dalla cartella Applicazioni nel Cestino.

Se ci sono modifiche non ancora caricate sul server remoto, l’app lo dice: la cosa giusta è collegarsi al server, aspettare che finiscano e riprovare. Se vuoi disinstallare lo stesso, devi scrivere OK: accetti di perdere quelle modifiche e MIMUS cancella dal Mac tutti i suoi file (copie dei file remoti, coda, impostazioni, password salvata). Sul server non viene cancellato niente.

Problemi frequenti

macOS dice che l’app «è danneggiata»

Succede a volte con le app scaricate da Internet non firmate da Apple. Apri il Terminale e scrivi:

xattr -cr "/Applications/MIMUS.app"

Poi riapri l’app.

macOS chiede di consentire a MIMUS l’accesso alla rete locale

Premi Consenti: serve per raggiungere il server remoto. Se l’hai negato per sbaglio: Impostazioni di Sistema → Privacy e sicurezza → Rete locale → attiva MIMUS, poi menu → Riavvia collegamento.

La cartella è vuota o non si apre

App → Riavvia collegamento. Se non basta, guarda Ultimi errori e manda una foto all’IT.

Sono in ufficio ma non vedo i file nuovi dei colleghi

Nelle cartelle che stai guardando compaiono da soli entro pochi secondi (in VPN entro un minuto circa); nelle altre entro 5 minuti (modificabile nelle Impostazioni). Per vederli subito: Aggiorna cartelle, dall’icona in alto o dall’app.

Non riesco a mettere un tag colorato a un file

Nella cartella collegata macOS non permette i tag del Finder né gli altri «attributi estesi» dei file. Se il Finder chiede nome e password premi Annulla: non funziona con nessun utente, nemmeno amministratore. I file si copiano e si salvano normalmente; dal Terminale usa cp -X al posto di cp.

Da fuori ufficio non si collega

Controlla che la VPN sia attiva. Senza VPN lavori offline con i file già sul Mac.

Un file non si apre offline

Ha il cerchio grigio: non era mai stato aperto su questo Mac (o era stato tolto perché non usato da 30 giorni) e si potrà aprire quando torni in rete. Prima di partire usa Scarica ora o Mantieni sempre su questo Mac sulle cartelle che ti servono.

Trovo file con «conflitto Mac» nel nome

Sono le tue versioni salvate in un conflitto (vedi messaggi). Confrontale con l’originale e cancella quella che non serve.
